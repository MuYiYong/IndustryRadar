## 2026-07-20｜W29 战略追加

### 行业机会判断

企业 AI 正从模型与 GraphRAG 竞争转向 Agent 的语义、权限、执行和证据基础设施。悦数可将图数据库定位从“复杂关系查询与分析引擎”升级为“企业 Agent 的关系与语义基础设施”。

### 建议产品叙事

> 悦数图不仅存储和查询关系，更为企业 Agent 提供语义理解、关系推理、权限判断、行动验证和证据追踪。

### 建议能力组合

1. AI 入口：AskGraph、GraphRAG、MCP、自然语言生成图查询与图算法；
2. 关系推理：多跳查询、路径分析、图算法、风险与影响传播；
3. 企业安全：SSO、证书认证、细粒度权限、审计、密钥和多租户；
4. 生产能力：高可用、备份恢复、滚动升级、资源管理和可观测性；
5. 语义治理：本体、规则、血缘、证据链、Dry Run 和行动约束。

### 优先差异化方向

- Agent Control Graph：统一建模 Agent、用户、工具、数据、规则、动作和影响；
- Ontology-driven Tools：由本体生成受约束工具和参数接口；
- Agent Dry Run：执行前模拟权限、规则、后续动作和业务影响。

## 2026-07-27｜W30 战略追加

### 产品定位升级

本周行业信号进一步证明，数据库、云平台和模型厂商都在争夺 Agent 时代的控制点。悦数不应只以 GraphRAG 或复杂图查询参与竞争，而应把图数据库、本体、AskGraph、MCP 和图算法统一为企业 Agent 的关系与语义基础设施。

### 建议统一叙事

> 悦数图是企业 Agent 的上下文状态层、关系推理层和行动证据层。

### 建议优先建设

1. Agent Control Graph：统一建模用户、Agent、角色、工具、数据、模型、规则、任务、行动、证据和影响；
2. Ontology-driven Tools：将本体中的合法对象、关系、参数和动作边界编译为受约束工具接口；
3. Agent Dry Run：执行前模拟权限、规则、后续影响和潜在冲突；
4. Context Graph 样板：选择监管报送、授信风险或供应链风险，展示状态变化到行动审计的完整链路；
5. Graph-guided Vector Search：用关系、本体、权限和时间范围约束向量候选，并以路径和规则完成重排。

### 面向 PostgreSQL SQL/PGQ 的竞争表达

> SQL/PGQ 推动图查询普及；悦数解决的是复杂关系智能的生产问题，包括大规模多跳遍历、路径分析、图算法、实时关系计算、GraphRAG 和 Agent 治理。

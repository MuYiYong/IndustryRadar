# 2026 年 7 月行业趋势累计报告

## 2026-07-20｜W29 周度追加

### 月度趋势演进

截至 7 月 19 日，企业 AI 的主线已从模型能力、RAG 和 Copilot，明显转向 Agent 的生产级运行与治理。核心能力集中在统一语义、身份权限、工具约束、行动审计、影响分析、停止与回滚。

### 本月阶段性判断

1. GraphRAG 正成为图数据库的基础能力，差异化开始转向上下文治理、时间与版本、权限策略和行动证据链。
2. 本体从业务词汇表升级为机器可执行的政策层，可用于生成受约束工具、定义动作前置条件和支持业务 Dry Run。
3. Agent Control Plane 正成为数据平台、云厂商、治理厂商和图数据库共同争夺的新入口。
4. 金融 AI 的治理目标从“可解释”升级为“可追责、可干预、可恢复”。
5. PostgreSQL 继续承担 Agent 状态和确定性记录，图数据库更适合关系推理、权限传播、风险传播与影响分析。

### 对悦数的累计启示

建议将产品能力组织为 AI 入口、关系推理、企业安全、生产能力和语义治理五层，并优先建设 Agent Control Graph、Ontology-driven Tools 与 Agent Dry Run。

## 2026-07-27｜W30 周度追加

### 月度趋势演进

截至 7 月 26 日，企业 AI 已从“Agent 数量增加”进一步进入“Agent 控制权下沉与分层治理”阶段。数据库厂商把身份、权限、协议和审计下沉到数据层；云厂商开始度量 Agent 会话、并发和资源；图数据库与本体则承担跨系统关系、业务语义、行动影响和证据链。

### 本月新增判断

1. 数据层治理与全局关系治理将并存：数据库负责本地强制执行，图与本体负责跨系统整体合法性判断。
2. Context Graph 正成为知识图谱的新一代产品表达，重点从静态知识转向状态、变化、影响和行动上下文。
3. Agent 可观测性正在形成独立基础设施层，会话、工具调用、成本、异常和业务影响都需要统一度量。
4. 本体开始承担运行时政策角色，除概念与关系外，还要定义动作、前置条件、审批要求和证据义务。
5. GraphRAG 的竞争重心转向上下文成本、路径证据和治理能力，单纯提高召回率不足以建立长期壁垒。
6. SQL/PGQ 会扩大图查询市场，但也要求专用图数据库用多跳性能、图算法、分布式能力和 Agent 治理证明差异化。

### 对悦数的累计启示

建议将“企业 Agent 的关系与语义基础设施”作为统一产品叙事，优先建设 Agent Control Graph、Ontology-driven Tools、Agent Dry Run 与 Context Graph 样板场景，并用 Graph-guided Vector Search 强化图与向量融合差异。
